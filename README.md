# ☕ Supermatrice

Projet réalisé dans le cadre du cours de **Programmation Orientée Objet (POO)** à l'École Supérieure Polytechnique (ESP/UCAD).

## 📖 Présentation

Ce projet consiste à développer une structure de données permettant de manipuler une **supermatrice** en Java. L'objectif était d'appliquer les principes de la programmation orientée objet pour concevoir une solution modulaire, réutilisable et efficace.

---

## 🚀 Fonctionnalités

- Allocation dynamique des matrices
- Permutation de lignes
- Extraction de sous-matrices
- Manipulation de structures matricielles
- Conception orientée objet

---

## 🛠 Technologies

- Java
- Programmation Orientée Objet (POO)
- Git
